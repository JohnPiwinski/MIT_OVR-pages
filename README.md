# Artin Wallpaper Symmetry Lab

A browser game and visual guide for Artin's wallpaper symmetry exercises. The static site is in `site/` and is deployed to GitHub Pages by the workflow in `.github/workflows/pages.yml`.

**Play the game:** [MIT OVR Symmetry Lab](https://johnpiwinski.github.io/MIT_OVR-pages/)

The deployment package contains only the game shell, its referenced art assets, and the wallpaper lab.
