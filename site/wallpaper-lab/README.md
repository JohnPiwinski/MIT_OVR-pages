# Wallpaper symmetry lab

Open `hippo-prototype/assignment.html` for the four-stage exercise, or `index.html` for the catalog. The exercise is also linked from Noether's office. No build step is needed to view it.

The two-domain stage can export either domain or a repeating, colored SVG tiling. The tiling export uses an SVG pattern with a four-by-four translation supercell; the SVG remains vector geometry and works with oblique lattices.

The four stages cover Artin M.5 parts (a)–(d): tile area, noncongruent domains, intersection/reassembly, and the point-group area formula. The domain stage can animate placing group-transformed copies to build a tiling. Its colors repeat on a four-by-four translation supercell and distinguish domains sharing an edge; this is not a claim that every symmetry preserves the colors. Regenerate those colors with `python3 wallpaper-lab/hippo-prototype/build_coloring.py` after changing domain geometry. Orbit points are generated from group actions; select a point to play an action, and choose from multiple actions where applicable. The hippo uses a smoothed and lattice-corrected contour; the fleur is extracted as an enclosed tile, cut along its mirror axis, and corrected to the measured D3 symmetry model. The brick wall uses a quarter-brick domain and an idealized running-bond lattice measured from the scan. The pointed-strip model completes a scan-extracted edge by reflection and translation. The zigzag model repeats scan edges using a checked half-turn group. The wavy-band model uses a scan-checked mirror and glide group. The diamond model preserves the source’s shaded/unshaded distinction. The overlapping-circle model repeats scan-extracted edges from a square-lattice domain; the staggered scallops use a scan-checked mirror and oblique lattice. See `hippo-prototype/README.md` for regeneration and accuracy details.

All 17 patterns appear in the four-stage exercise. Eight remain drafts because their group placement still needs validation against the scans. The seven manually traced tile polygons (patterns 3, 4, 5, 7, 10, 14, and 15) record their overlap with the chosen OpenCV component; their intersection-over-union scores range from 0.964 to 0.991, and the generator rejects scores below 0.9. The exercise draws those cleaned tile polygons directly as colored SVG, repeated by the group's transformations, and the SVG export uses their clean outlines instead of the noisier OpenCV ink trace. The generated `patternFragmentPath` remains available for scan comparison. Each draft stores a raster edge-match score at a 2.5 px tolerance to help target manual review; this is a registration measure, not a wallpaper-group classification. Patterns 3, 4, 5, and 15 have scan-fitted domain phases, and the phase adjustments preserve exact group tiling. For the rosette, Hough detections fit the circle radius and triangular lattice at 4.6 px RMS. The angular strip and herringbone use explicit, manually placed glide-strip and pgg rectangular domains instead of arbitrary Voronoi cuts. Patterns 14, 15, and 17 use hand-defined mirror chambers. The generator checks each domain's area, then intersects all group images with one translation cell and rejects any uncovered area or interior overlap. For pattern 10, repeated-edge registration places the pgg 2-fold point near (184.5, 152.5); the estimated primitive vertical period is 112 px, with a 56 px glide. These checks establish consistency with the estimated group model and traced tile, but do not confirm the group placement against the source figure. Run `python3 wallpaper-lab/hippo-prototype/build_provisional.py` to regenerate the draft geometry, then `python3 wallpaper-lab/hippo-prototype/build_coloring.py` to regenerate adjacency colors.

Run checks with `python3 -m unittest discover -s wallpaper-lab/hippo-prototype -p 'test_*.py' -v`. Python processing uses OpenCV, NumPy, SciPy, Shapely, and NetworkX; generated browser assets need no Python installation.
